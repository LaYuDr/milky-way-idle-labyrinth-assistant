# 迷宫助手

《银河奶牛放置》的独立用户脚本，提供迷宫路线规划、房间计算、推荐等级、挑战档案和代币规划。当前版本 **0.12.7**。

## 安装与使用

安装 Tampermonkey 后，导入 [Greasy Fork 正式安装页](https://greasyfork.org/zh-CN/scripts/605612)。正式安装包不依赖本机开发服务。

启用前请停用原版《迷宫胜率计算器》及本助手的开发加载器，刷新游戏页面；同类计算器只启用一份，避免重复面板与计算。

- 迷宫地图旁显示路线与房间计算，支持地图缩放和探照灯规划。
- 原生自动化页显示房间推荐，可按胜率、预计耗时或经验效率计算推荐等级。
- 迷宫商店旁显示代币规划，可安排升级与兑换顺序，查看预算及收入记录。
- 点击房间查看计算详情；日志与胜率分布从计算面板进入。

默认使用上述原位置布局，右侧页签布局保留为开发选项，默认关闭。

## 功能与边界

路线优先减少新开格子，同成本时比较顺路收获的外扩机会及直接揭示数。挑战房沿用游戏等级颜色：红色避开，白色可走；未知房间暂按可能通过估算，不保证战斗胜率。路径随可见地图及原生队列变化更新。

生活与强化房间在本地计算成功率、预计通关时长和经验效率。战斗使用内置 Rust/WASM 引擎，按所选场数模拟，每场严格 120 秒截止；结果为估计值。生活与强化挑战可显示实时重开建议。

插件不移动、不挑战、不领取、不购买或兑换，不自动保存游戏设置。启用“编辑时填入推荐等级”后，只有点击当前行“编辑”才预填草稿，保存仍需玩家手动完成。

挑战档案及计算结果保存在本机，按角色隔离。右键战斗房主动打开外部模拟器时，会通过 URL hash 传递装备、技能等模拟配置。

## 隐私与统计

计算、角色设置与挑战档案均在本机处理。正式安装包默认开启安装与活跃统计，可在计算面板下方的统计设置中关闭；只发送插件标识、版本和随机安装标识的 SHA-256 摘要，不发送账号、角色、装备、迷宫档案、操作记录或 Cookie。关闭时仅尝试发送一次不含安装标识的关闭事件。服务端可见来源 IP，详细说明见 [安装与活跃统计](docs/USAGE_STATISTICS.md)。

开发加载器、测试服和外部模拟器不计入正式统计。统计服务不可用不会阻塞助手功能。

## 开发与验证

使用 Node.js 24 或以上版本：

```bash
npm ci
npm run check:handoff
npm run serve
```

本地服务地址为 `http://127.0.0.1:4186/`。开发加载器为 `http://127.0.0.1:4186/milky-way-idle-labyrinth-dev-loader.user.js`，与正式安装包只启用一个。

也可使用 `启动开发服务.command`。端口在 `release.config.json` 中设置，端口被占用时不会结束其他进程。

浏览器测试使用本地夹具与合成角色数据，真实游戏验收另行记录。路线实验台可打开 `dist/route-lab.html` 离线使用。
