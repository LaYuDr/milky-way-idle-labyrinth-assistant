# 迷宫代币规划

默认点击迷宫页面中、商店旁的“代币规划”页签；启用右侧布局时，从“迷宫助手”进入“代币规划”。顶部仅显示规划数量和剩余数量，下方保留使用计划及商店目录。

## 数量与预算

- 规划数量留空时使用当前背包代币，背包变化时自动更新。占位文字显示当前数量。
- 手动填写后使用填写值；0 是有效预算，不会回退到背包数量。
- 剩余数量 = 规划数量（留空则为当前数量）− 计划总花费。超出预算显示红色负数；未知余额或费用显示横线。
- 旧方案中的保留代币、挑战次数、单次收入和预测起点不再参与页面计算、复制或计划导出。原存储格式仍兼容，不删除已有记录。

例如背包有 153 代币，计划花费 60：留空显示剩余 93；填写 100 显示 40；填写 0 显示 −60。

## 使用计划与目录

支持 14 种迷宫商店升级及客户端提供的代币兑换商品。目录可搜索和分类；点击加入目标，重复点击定位已有项目。

- 升级选择目标等级，费用逐级累加。游戏等级提升后按新等级计算剩余费用；目标已达到时显示“已完成”。
- 商品填写兑换次数，按次数乘单价计算。兑换完成后由玩家手动调整或移除计划。
- 保留拖动、上下按钮、Alt 加上下方向键排序，以及费用明细和预算不足提示。
- 保留复制计划、导出计划 CSV、清空与撤销。清空后的撤销入口保留 8 秒；之后编辑计划会结束撤销机会。
- 宽屏并排显示计划与目录，窄屏纵向排列。

只保存本地方案，购买和兑换仍由玩家在游戏商店完成。

## 保存与兼容

数据库为 `mwi-labyrinth:tokens:v1`，对象仓库 `characters`，格式版本 `schema: 1`，按网站来源及角色 ID 隔离。保存失败保留修改并提供重试；读取失败不会用空方案覆盖原数据。

收入统计、预测和收入导出入口已从页面删除。已有收入档案保留，后台原有的被动记录仍兼容，不影响预算。数据来自已有 `characterLabyrinth.lootedItemsData` 与被动接收的 `labyrinth_updated` 消息；不上传游戏数据。

升级上限、花费和等级换算按 2026-11-10 检查的本地游戏客户端 `getUpgradeMaxLevel`、`getUpgradeCost`、`getUpgradeLevelFromCharacterInfo` 实现；兑换商品和价格读取当前页面 `initClientData.labyrinthShopItemDetailMap`。游戏若调整升级规则，需要同步更新 `src/tokens/model.js`。缺少明确等级字段时不推测零级。

## 验证

`test/tokens.test.js` 检查成本、排序预算、未知值及旧数据兼容。`tools/browser-tokens.mjs` 使用离线游戏结构和真实浏览器 IndexedDB，覆盖两栏布局、空值跟随余额、显式零值、超支负数、旧预测隔离、目录与排序、撤销、复制导出、刷新恢复及保存失败重试。

这些用例不访问游戏服务器、不触发购买或挑战，不能代替真实游戏验收。
